# Fracture Finder

90-second diagnostic for LinkedIn stalls. Find out if your avatar, offer, or copy is broken.

## Live Demo

[fracture-finder.vercel.app](https://fracture-finder.vercel.app)

## Deploy Your Own

### 1. Fork this repo

Click the "Fork" button above.

### 2. Connect to Vercel

1. Go to [vercel.com](https://vercel.com)
2. Import your forked repo
3. Framework: **Other** (static HTML)
4. Deploy

### 3. Custom Domain (optional)

In Vercel dashboard → Project Settings → Domains → Add your domain

## Local Development

```bash
# Clone
git clone https://github.com/YOURUSERNAME/fracture-finder.git
cd fracture-finder

# Serve locally
npx serve
```

## How It Works

1. Answer 5 diagnostic questions
2. Get your primary fracture: Avatar, Offer, or Copy
3. Book your Fracture Map call
